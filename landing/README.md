# Fractyco — landing

The public marketing site: hero, how-it-works, offerings, compliance,
on-chain programs, FAQ.

**Demo:** https://fractyco--landing.at.symbo.ls

```sh
npm run start   # http://localhost:5040
```

Only page sections and the navbar live here; every primitive and the design
system come from [`../brand`](../brand). Account CTAs point at the investor
app. The offering cards are labeled illustrative until the backend `projects`
table has rows.
